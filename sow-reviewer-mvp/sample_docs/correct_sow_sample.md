# Statement of Work: Customer Support Chatbot

This SOW is between Acme Analytics (the Vendor) and Northwind Retail (the Client).

## 1. Project Scope & Objectives

In-Scope: design, build and deploy a customer support chatbot for order-status and returns questions, with an admin web UI for prompt management.

Out-of-Scope: voice channels, languages other than English, integration with the Client's legacy CRM, and any hosting or support after the 30-day warranty period.

## 2. Deliverables Schedule

| ID | Deliverable | Format | Target Date | Owner |
|---|---|---|---|---|
| D1 | Requirements document | PDF | 2026-01-16 | Vendor Delivery Lead |
| D2 | Chatbot prototype | Hosted demo | 2026-02-13 | Vendor Data Scientist |
| D3 | Production chatbot and admin UI | Deployed application | 2026-03-27 | Vendor Delivery Lead |

## 3. Acceptance Criteria & Sign-Off

- D1 is accepted when the Client Product Owner approves the requirements in writing.
- D2 is accepted when intent accuracy is at least 90 percent on the agreed 500-sample test set.
- D3 is accepted when D2 criteria are met in production and the admin UI passes the agreed test checklist.

The Client has five (5) business days to review each deliverable. If no written feedback is received within that window, the deliverable is deemed accepted. Up to two (2) revision rounds per deliverable are included.
