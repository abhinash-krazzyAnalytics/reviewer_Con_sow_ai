# Statement of Work: Customer Support Chatbot

This SOW is between Acme Analytics (the Vendor) and Northwind Retail (the Client).

## 1. Project Scope

The Vendor will build a customer support chatbot and a web UI for the Client. Unlimited revisions to the chatbot prompts and UI are included in the fixed fee.

## 2. Deliverables

| ID | Deliverable | Format | Target Date |
|---|---|---|---|
| D1 | Requirements document | PDF | TBD |
| D2 | Chatbot prototype | Hosted demo | TBD |
| D3 | Production chatbot and UI | Deployed application | TBD |

## 3. Delivery Approach

The Vendor will deliver in iterations. Each deliverable is considered complete once it is approved to the Client's full satisfaction.

## 4. Commercials & Payment

The total contract value (TCV) is USD 120,000 on a fixed-fee basis. 50 percent is billed at project start and 50 percent on completion. Invoices are payable Net 30.
